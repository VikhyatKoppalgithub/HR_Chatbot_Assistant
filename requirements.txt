# Install CPU-only PyTorch.
#
# This line is load-bearing for deployment. On Linux, plain `pip install torch`
# pulls the CUDA build: an ~800MB wheel that unpacks to ~2.5GB of GPU libraries
# which are completely unused on a CPU host, and which will blow past the disk
# and memory limits of every free hosting tier.
#
# The PyTorch CPU index publishes versions tagged `+cpu` (e.g. 2.8.0+cpu).
# Under PEP 440 a local-version tag sorts ABOVE the plain release, so pip
# prefers the CPU wheel when both indexes are visible. On macOS there is no
# separate CPU build and this quietly falls back to PyPI, so it is safe locally.
--extra-index-url https://download.pytorch.org/whl/cpu
